# Security Policy

## Supported version

Security fixes are applied to the latest commit on `main`.

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub's security advisory feature. Include the affected file or workflow, reproduction details, and potential impact. Do not open a public issue for an unpatched vulnerability.

## Data handling

Do not include production conversations, credentials, personal data, or customer records in eval fixtures, logs, screenshots, issues, pull requests, or generated reports. The included redaction is defense in depth and is not a substitute for synthetic data, data classification, or access control.

Read [`docs/THREAT-MODEL.md`](docs/THREAT-MODEL.md) before connecting external models, tools, or data stores.
